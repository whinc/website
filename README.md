## 小而美工具

一个微信小程序，装下日常会用到的各种小工具。每款只做一件事，共用一套 iOS 质感的界面，打开就知道怎么用。

- **日历与农历**：万年历、老黄历、节日节气、择吉日、佛历、道历、养生钟、时钟、生日查询、纪念日倒计时
- **健康**：成人 BMI、儿童身高体重、青少年身高体重、四季色彩
- **算账**：房贷计算、个税计算器、退休年龄、单位换算、计算器
- **生活**：亲戚称呼、二维码制作与美化、手电筒、表情符号、敲木鱼、尖叫鸡、补光灯

不用下载 App，不占手机桌面；换手机后重新扫码即可。免费版有少量广告，看一段视频可得 VIP 时长免广告。

## 小青蛙伴学

小学课内同步的短练习。每页只做一件事，孩子打开就知道该点哪里；答对庆祝，答错鼓励再试，没有红叉、没有倒计时、没有排名。

- **拼音**：声母、韵母、整体认读音节、四声、拼读、音节表、易混音对比，每个音节都能点读
- **汉字与古诗**：课内生字按学期分册，笔顺动画 + 词组 + 拼音 + 发音；古诗逐句跟读高亮
- **数学**：数一数、加法、减法、20 以内凑十破十，用图形演示
- **英语**：字母发音、主题单词听音选图、听读跟读

没有充值入口，学习内容免费；孩子学习的页面里没有广告、没有弹窗、没有开屏广告。学习进度和奖励存在手机本地。

## 共同的取舍

- **不用注册**：没有账号、手机号或表单，打开微信就能用。
- **数据留在本机**：输入和进度不上传服务器。
- **一个人维护**：不做课程、不做题库、不承诺提分，也不写无法验证的宣传。
